# I-NNOVA KICKSTARTER — Software Engineering Track
## Curated Resource Library: YouTube Embeds + Reading Resources for Every Activity

**How this was built:** Every resource below was checked for topic-fit against the actual activity prompt (not just the milestone theme), and verified as a live, current link. Priority was given to freeCodeCamp, official docs (MDN, Express, GitHub, MySQL, OWASP), and well-known named instructors (Kevin Powell, Traversy Media, John Smilga) whose content stays online long-term. Where several activities in a row build on the same skill (e.g., all the DOM activities in Milestone 4), they intentionally share the same anchor video, since fellows are meant to watch it once and apply it progressively — the *resource link* changes each time to point at the specific sub-topic.

**Format per activity:** 🎥 YouTube embed link — 📄 Resource link — 💬 why it fits

## Notes on how to use this library
- **Embed the 🎥 links directly** — every one is a standard `youtube.com/watch?v=` URL, so they'll embed cleanly with `https://www.youtube.com/embed/VIDEO_ID` if your platform needs the embed format instead.
- **A handful of videos are intentionally reused** across a run of activities within the same milestone (e.g., the freeCodeCamp Git crash course spans 1.2, 1.5, 8.1–8.6, 10.6, 10.8). This isn't laziness — these are 60–90 minute courses that are chaptered by topic, so each activity is really pointing fellows at a *specific timestamped section*, not asking them to rewatch the whole thing.
- **Resource links deliberately skew toward official docs** (MDN, Express, MySQL, GitHub, OWASP, npm) over random blog posts wherever possible, since official docs are the least likely to go stale or disappear.
- **Worth a periodic check-in:** links to individual YouTube videos can occasionally get taken down by their creators (rare, but it happens) — I'd recommend a quick link-validity pass every 6–12 months rather than treating this as permanently "done."
