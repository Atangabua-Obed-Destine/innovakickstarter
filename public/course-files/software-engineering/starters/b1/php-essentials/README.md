# PHP Essentials for JavaScript Developers (Chapter 7, Backend)

One file: `php-essentials.php`. It holds a few Nkwen Traders products, seven TODOs and a self-check.

## Run it

- **With PHP installed:** open a terminal in this folder and run `php php-essentials.php`.
- **Without PHP yet:** open https://onlinephp.io, choose PHP 8.3 or newer, paste the whole file and click **Execute Code**.

At first the self-check lists 8 problems. That is expected.

## Steps

1. Read the data at the top. Compare it with the JavaScript you already know.
2. Do TODO 1 to TODO 7 in order. Run the file after each one.
3. Each time, the list of problems should get shorter.
4. Stop when you see `Self-check passed: every TODO works.`
5. Answer the three questions from the lesson in a comment at the very top of the file.
6. Save the file in your `innova-software-engineering` repository as `ch07-backend/php-essentials/php-essentials.php`, commit and push.

Do not edit the self-check at the bottom. If it complains, your code needs fixing, not the check.
