# Definition of done

A story is **done** only when every box below is true. Not "done except the tests". Done.
The squad agrees this list in Sprint Planning. You may change it only in a retrospective.

## Every story
- [ ] All its acceptance criteria are met, and someone other than the author checked them.
- [ ] The code reached `main` through a pull request with at least one approval.
- [ ] CI is green on the pull request: every job.
- [ ] New behaviour has tests (feature tests, component tests or widget tests).
- [ ] If it calls or changes the API, it follows `contract/README.md`, and the contract tests pass.
