# Wireframes

A **wireframe** is a rough drawing of a screen: boxes, labels and buttons, no colours.
Paper and a phone photo are fine. So are Excalidraw (excalidraw.com) or Penpot (penpot.app), both free.

Put the pictures in this folder (PNG or JPG, under 500 KB each, so they are quick on mobile data),
or link to them below. Draw phone-sized screens first: most Nkwen customers use a phone.
