# Interview practice: data structures and algorithms

Six short problems like the ones online coding tests ask, with Nkwen data. JavaScript, no packages.
Put this folder in your course repository as `ch11-job-ready/dsa/`.

## Files
| File | What it is |
|---|---|
| `problems.js` | **Your work:** six functions, each with a TODO and a hint. |
| `problems.test.js` | Self-checks. Do not change them. |

## Steps
1. Run `node --test`. You should see 0 passed and 7 failed with `Error: TODO`.
2. Solve one problem at a time. Say your plan out loud first, then code, then run `node --test`.
3. Write the Big-O of each solution in a comment above it, for example `// O(n) time, O(n) memory`.
4. Finish when `node --test` shows 7 passed.

Tip: the "fast enough" test gives a big list. Two nested loops take seconds there; a Map takes milliseconds.
