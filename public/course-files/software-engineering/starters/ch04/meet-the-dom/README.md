# Meet the DOM: read the Mile 4 branch page

## Files
- `index.html`: the Mile 4 branch page. Read it first: note the ids and classes.
- `dom.js`: 7 TODOs. Use exactly the variable names given.
- `self-check.js`: checks your variables against the page. Do not edit it.

## Steps
1. Open `index.html` in Chrome or Edge. Open DevTools (F12): the **Elements** tab shows the DOM tree, the **Console** tab shows your `console.log` output.
2. Do TODO 1 to TODO 7 in `dom.js`. Save and refresh after each one.
3. Read the **Self-check** list at the bottom of the page. "NOT YET" lines include a hint.
4. In the Elements tab, click the `<ul id="shelf">`. In the Console, type `$0.children.length` and press Enter. `$0` is the element you selected.
