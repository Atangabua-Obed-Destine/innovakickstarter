# Strings, Numbers & Dates for Money (Chapter 2)

- `money.js`: six helpers to write (`TODO`s).
- `money.test.js`: self-checks. Do not change it.
- `explore.js`: small experiments to run before you write any code.

## Steps

1. Copy this folder into your repository as `ch02-javascript/money/`.
2. Run `node explore.js`. Read each line of output and the comment above it.
3. Run `node --test`. The checks fail: the helpers are empty.
4. Write the helpers in order. Run `node --test` after each one.
5. Commit and push.
