# Functions & Reusability (Chapter 2)

- `pricing.js`: five pricing functions to write (the `TODO`s).
- `try.js`: a place to call your functions with different inputs.
- `pricing.test.js`: self-checks. Do not change it.

## Steps

1. Copy this folder into your repository as `ch02-javascript/functions/`.
2. Run `node --test`. The checks fail: the functions are empty.
3. Write the functions one at a time, in order. Run `node --test` after each one.
4. In `try.js`, call each function three times. Write the answer you expect in a comment first.
5. Run `node try.js` and compare.
6. Commit and push.
