# Your First Tests (Chapter 2)

- `till.js`: three till functions. They are already written.
- `till.test.js`: one example test and some `TODO` tests. You write the tests.

## Steps

1. Copy this folder into your repository as `ch02-javascript/first-tests/`.
2. Run `node --test`. One test passes; the `TODO` tests fail on purpose.
3. Read `till.js`. For each function, list: one normal case, the edges, and the error cases.
4. Replace each `TODO` test with a real test. Add more until you have at least 8.
5. Run `node --test` until everything passes.
6. **Break it on purpose:** make one small change in `till.js` (see the lesson). Run the tests. At least one must fail. Undo the change.
7. Commit and push.
