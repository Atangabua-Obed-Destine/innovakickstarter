# Arrays & Objects (Chapter 2)

- `nkwen.json`: the 20 Nkwen Traders products, with stock at each branch.
- `catalogue.js`: five functions to write (`TODO`s).
- `show.js`: prints a catalogue for one branch (`TODO`s).
- `catalogue.test.js`: self-checks. Do not change it.

## Steps

1. Copy this folder into your repository as `ch02-javascript/arrays-objects/`.
2. Open `nkwen.json` and find Rice 50kg. Say out loud what each key means.
3. Run `node --test`. The checks fail: the functions are empty.
4. Write the five functions in order. Run `node --test` after each one.
5. Finish `show.js` and run `node show.js`. Count the lines: there should be one per product.
6. Change `BRANCH` and run again.
7. Commit and push.
