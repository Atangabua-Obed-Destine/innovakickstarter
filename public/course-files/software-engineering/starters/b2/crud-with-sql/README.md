# CRUD with SQL (starter)

1. `load-nkwen.sql`: run it first. It (re)creates `products`, `branches` and `stock` in the `nkwen_sql` database
   with the Nkwen practice data. Run it again whenever you want to start over.
2. `crud.sql`: your 12 tasks. Write each query under its TODO.
3. `check-crud.sql`: run it after the write tasks (Q4 to Q9). Every line should say PASS.
4. `injection-demo.php`: run `php injection-demo.php` and read what it prints.
   If your MySQL user is not `root` with no password, change the second line of the file.
