# Dart for JavaScript Developers (Chapter 7, Mobile)

One file: `dart_basics.dart`. It holds seven Nkwen Traders products, eight TODOs and a self-check.

## Run it
- **No install:** open https://dartpad.dev, paste the whole file and press **Run**.
- **With Flutter or Dart installed:** open a terminal in this folder and run `dart run dart_basics.dart`.

At first the self-check lists 16 problems. That is expected.

## Steps
1. Read the data at the top. Compare it with the JavaScript you know.
2. Do TODO 1 to TODO 8 in order. Run the file after each one; the list of problems gets shorter.
3. Stop when you see `Self-check passed: every TODO works.`
4. Answer the three questions from the lesson in a comment at the very top of the file.
5. Save it in your `innova-software-engineering` repository as `ch07-mobile/dart-basics/dart_basics.dart`, commit and push.

Do not edit the self-check at the bottom. If it complains, your code needs fixing, not the check.
