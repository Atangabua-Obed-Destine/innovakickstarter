# Mini Project: your developer portfolio page

This is **your** page, not Nkwen Traders'. Recruiters will open it. It will grow with every chapter: you will add projects, and later some JavaScript.

## Where it lives
Your portfolio gets its own repository called `<your-username>.github.io` (use your real GitHub username). GitHub Pages then publishes it at `https://<your-username>.github.io`. That short address looks good on a CV.

## Steps
1. On GitHub, create a **public** repository named exactly `<your-username>.github.io`, with a README.
2. Clone it, copy `index.html` and `style.css` into it, and open `index.html` in your browser.
3. Fill every TODO in `index.html` with your own words. Keep sentences short.
4. Style it mobile-first in `style.css`: phone first, then `@media (min-width: ...)`.
5. Test at 360px, 768px and 1280px. Run Lighthouse (Accessibility, Mobile).
6. Commit and push. On GitHub: **Settings > Pages > Source: Deploy from a branch > main > / (root) > Save**. Wait 1-2 minutes, then open your address.

## Self-check
- [ ] It is live at `https://<your-username>.github.io`.
- [ ] At 360px there is no sideways scroll, and the text is readable without zooming.
- [ ] Lighthouse Accessibility (mobile) is 90 or higher.
- [ ] At least 2 projects, each with a working link.
- [ ] No phone number or home address on the page.
