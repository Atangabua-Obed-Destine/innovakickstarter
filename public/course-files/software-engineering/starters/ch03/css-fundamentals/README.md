# CSS Fundamentals: style the Nkwen Traders page

You will style the page you built in **HTML Fundamentals**. Keep your HTML. Add this stylesheet.

## Files
- `style.css`: the brand colours are ready. Every other rule is a TODO.

## Steps
1. Copy `style.css` into the same folder as your `index.html` from the HTML lesson.
2. Add `<link rel="stylesheet" href="style.css">` inside the `<head>`.
3. Test the link: add `body { background: lightblue; }`, save and refresh. Blue? The link works. Remove the test rule.
4. Do TODO 2 to TODO 11 in order. Save and refresh after each one.
5. Open DevTools (F12), click an element and look at the **box model** diagram in the Styles or Computed tab.
