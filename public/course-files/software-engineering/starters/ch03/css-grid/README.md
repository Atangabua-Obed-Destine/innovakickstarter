# CSS Grid: the weekly product grid

Eight Nkwen Traders products are already in `index.html`, and the cards are styled. You will lay them out with CSS Grid.

## Steps
1. Open `index.html` in your browser. The cards sit in one long column.
2. Open DevTools (F12) and turn on the device toolbar (Ctrl+Shift+M). Set the width to 360.
3. In `style.css`, do TODO 1 to TODO 4. After TODO 3, note what goes wrong at 360px.
4. In DevTools, click the small **grid** badge next to `<ul class="product-grid">` in the Elements panel. It draws the grid lines.
5. Do TODO 5 and TODO 6. Compare the two ways of making the featured card wide.
6. Write down how many columns you see at 360px, 768px and 1280px.
