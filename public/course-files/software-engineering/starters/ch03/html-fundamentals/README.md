# HTML Fundamentals: the first Nkwen Traders page

Build the first, unstyled web page for Nkwen Traders Ltd. No CSS yet: today is about **structure**.

## Files
- `index.html`: the page. It has TODO comments. Replace each TODO with real HTML.
- `logo.svg`: the company logo. Keep it in the same folder as `index.html`.

## Steps
1. Open this folder in VS Code. Open `index.html` in your browser (double-click it, or use Live Server).
2. Do TODO 1 to TODO 7 in order. After each one, save and refresh the browser.
3. Check your HTML at https://validator.w3.org/#validate_by_input : paste all of it and click **Check**.
