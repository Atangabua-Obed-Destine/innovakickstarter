# AI Check (Chapter 1)

An AI assistant wrote `basket.js` and three tests. The tests pass, but the function has one hidden bug.

## Steps

1. Copy this folder into your repository as `ch01-first-day/ai-check/`.
2. Open a terminal in the folder and run `node --test`. Three tests pass and one fails: the failing one is your `TODO`.
3. Read `basket.js` line by line. Under each line, write a comment that starts with `// Means:` and says what the line does in your own words.
4. Read the prompt at the top of `basket.js` again, word by word. Compare each rule with the code.
5. When you find the bug, replace the `TODO` test with a test that shows it. Run `node --test`: your test must **fail**.
6. Fix `basket.js` with the smallest change. Run `node --test`: all four tests must **pass**.
7. Commit and push.

## Rules

- You may ask an AI tool to **explain** the code. Do not ask it to find or fix the bug for you.
- Never paste passwords, keys or customers' personal data into an AI tool.
