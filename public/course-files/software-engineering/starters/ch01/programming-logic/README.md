# Programming Logic (Chapter 1)

Two files:

- `predict.js`: six short blocks. Predict each output first, then run `node predict.js`.
- `exercises.js`: four small exercises. Write code under each `TODO`, then run `node exercises.js`.

## Steps

1. Copy this folder into your `innova-software-engineering` folder as `ch01-first-day/programming-logic/`.
2. Open the folder in VS Code and open a terminal (**Terminal > New Terminal**).
3. In `predict.js`, write a prediction on each `// My prediction` line. Do not run it yet.
4. Run `node predict.js`. Compare each line with your prediction.
5. For each wrong prediction, write one sentence under it: why did the computer do that?
6. Do the four exercises in `exercises.js`. Run the file after each one.
7. Check every number by hand. A program that runs is not always a program that is right.

There are no automated tests in this activity. You will meet tests in the Restock Alerts project.
